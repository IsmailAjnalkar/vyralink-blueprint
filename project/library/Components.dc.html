Accessibility rules for every component

  • Real buttons, links and inputs; no clickable divs.
  • Text contrast at least 4.5:1 (secondary text #3d3d3d on white).
  • Touch targets at least 44 × 44 px.
  • Visible focus outline on every interactive element (Phase C: 2 px, offset 2 px).
  • Icons that carry meaning have labels; decorative icons are hidden from screen readers.
  • Status and data source are written in words, never colour alone.
