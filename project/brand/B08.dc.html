Spec notes · B08MVP
Purpose. Every campaign and its status in one list, with the next action for each.
Roles. Brand Owner, Brand Marketing Manager.
Rules
  • Status names and order are shared across brand, seller and operations portals.
  • Cancelled is only possible before In progress; Disputed only after Completed.
  • Transitions are server-side and audit-logged; the table refreshes on change.
  • Partially completed sessions (interrupted LIVE) complete with a “Partial” flag.
States and errors
  • Empty → create campaign
  • Load error → retry
  • Pending approval → Approve action for Owner only
