Spec notes · O12MVP
Purpose. Front desk view of today’s arrivals; the official arrival record.
Roles. Front desk (Location Manager or delegate), producers.
Rules
  • Check in by scanning the seller’s code (C15) or entering it; photo ID compared with the profile.
  • Check-in time drives on-time and no-show rules.
  • No-show at arrival + 15 min: producer calls seller; manager decides backup seller, delay or reschedule.
  • Backup seller must hold the campaign’s required certificates.
States and errors
  • Wrong day or location → shows the seller’s actual booking
  • ID doesn’t match → don’t check in; manager review
  • No-show → backup workflow
