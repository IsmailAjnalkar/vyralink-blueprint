Spec notes · O22MVP
Purpose. Rules that make bookings, check-ins and incidents work the same way every time.
Roles. Location Manager (location), Super Admin (platform defaults).
Rules
  • Location values override platform defaults; blank inherits the default.
  • Changes apply to new bookings; existing bookings keep the rules they were made under.
  • Every change is audit-logged (A09).
States and errors
  • Value outside allowed range → inline error
  • Change affects signed contracts → blocked; applies to new ones only
