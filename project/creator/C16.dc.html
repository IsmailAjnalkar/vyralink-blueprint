Product
Vitamin C Face Serum$40 · LIVE-only 15% off in TikTok Shop

Say this

  • Contains 15% vitamin C
  • Fragrance-free formula
  • Use every morning before sunscreen
  • Returns follow TikTok Shop’s returns policy

Never say

  • That it treats or clears acne, melasma or any condition
  • That it removes wrinkles or reverses ageing
  • “Dermatologist recommended”
  • Results in a set number of days
