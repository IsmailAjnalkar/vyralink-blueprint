Spec notes · O08MVP
Purpose. Track kit per booth and session, and swap failures fast.
Roles. Producers, Location Manager.
Rules
  • Each item has an ID, booth, status: OK, Needs check, Repair, Retired.
  • Session kit is copied from the booth standard kit and can be adjusted.
  • Failure logged during a LIVE opens an incident (O16) automatically.
  • Backup kit is reserved per shift, not per session.
States and errors
  • Item marked Repair with upcoming sessions → swap prompt
  • Backup kit already in use → escalate
