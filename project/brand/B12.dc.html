Spec notes · B12MVP
Purpose. Run invitations, applications and counter-offers until a booking is confirmed.
Roles. Brand Marketing Manager, Brand Owner; seller side in C11.
Rules
  • Invites expire after 48 h (configurable); expiry and response notify both sides.
  • Each counter is a new version; only the latest can be accepted.
  • One seller per LIVE slot: confirming one withdraws other open invites for that slot.
  • Booking needs the studio hold still valid; else re-select the slot.
States and errors
  • Declined → suggested next sellers
  • Expired → resend
  • Hold expired → choose slot
  • Missing certification → booking blocked until passed
