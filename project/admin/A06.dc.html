Spec notes · A06MVP PHASE 2
Purpose. How sales data gets in: import templates now, authorized connections later.
Roles. Platform Super Administrator.
Rules
  • MVP: CSV import templates map TikTok Shop report columns to Vyralink fields (used in O17).
  • Phase 2: connections only through access TikTok officially authorizes for each shop; scopes listed; no scraping, no stored passwords.
  • Vyralink never controls a shop or a LIVE; it reads results it is allowed to read.
  • When a connection fails, the brand falls back to manual import automatically.
States and errors
  • Template mismatch (report format changed) → import errors list, update mapping
  • Connection revoked by the shop → status Disconnected, brand notified
